A mood-based music recommendation system built on a Spotify dataset of 114,000 tracks.

How it works:
The system engineers 8 audio features (valence, energy, danceability, tempo, instrumentalness, acousticness, speechiness, popularity) into a custom scoring algorithm that classifies each track into one of 5 mood categories: Happy, Chill, Sad, Hype, or Focus. Users select a mood and preferred genres, and the system returns ranked recommendations sorted by popularity and mood score.

Tech Stack: Python, Pandas, Jupyter Notebook
Dataset: Spotify Tracks Dataset (Kaggle) — 114,000 tracks
